Change 1, tier-gated scale TTA replacing pose-SAHI (patch_v153.py):
  MULTISCALE_PADDINGS = (1.15, 1.2, 1.3, 1.35), MULTISCALE_MAX_TIER = 1. While the wall-clock controller is at tier
  <= 1 and has not disabled the former SAHI path by time (6,600 s budget) or by its measured-deadline calibration,
  every member uses these four square-crop paddings, each with horizontal flip, equal weights, instead of (1.2, 1.3).
  The pose-guided zoom views (pose-SAHI) never run (the zoom gate now requires MULTISCALE_PADDINGS to be empty; the
  CPU smoke switch that forced the zoom path for the first four CPU images is therefore inactive). At tier >= 2 or
  after the time budget the original (1.2, 1.3) views are used. The crop-rounding correction averages over the
  active paddings (identical arithmetic for two paddings).
Change 2, confidence-preserving fusion (patch_v154.py):
  FUSION_KEEP_CONFIDENCE = True. Each member's per-joint unit-peak heatmap is multiplied back by that member's own
  per-joint peak value (clamped to [1e-6, 1]) before the per-joint anatomical weighted mean, so a less confident
  member contributes less. The per-member consensus maps used by the person score are unchanged (unit peak).
